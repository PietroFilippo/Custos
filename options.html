Settings

Custos does not run in private windows. Timers, adult-site blocking, and X protection are all inactive there. To include them, open about:addons, choose Custos, and set Run in Private Windows to Allow.

Locks can’t be shortened or removed early. While something is locked, it can only get stricter.

Site timers

Each site counts only while its tab is focused. At the limit its tabs close, and the site can stay blocked for a while. A rule for example.com also covers its subdomains.

“Unblock now” asks for a second click to confirm. Deleting a site shows an Undo notice for a few seconds.

Adult websites

Blocks known pornography websites and their subdomains using a list bundled with the extension. Matching happens on this device. It is a known-domain blocker, not a content scanner.

Google, Bing, DuckDuckGo, and Brave Search always use their strictest filter, including image search. Needs adult-site blocking on and shares its lock.

Turning this on also blocks matching tabs that are already open. If the bundled list ever fails to load, navigation is held and the popup shows “Check settings”. Mixed-content sites such as X use the separate protection below.

X / Twitter protection

Hides sensitive media on x.com. Everything runs on this device; no media or scores leave the browser.

Protection level

Balanced is the recommended starting point. Strict hides more and misfires more; Lenient hides less and needs two strong video frames before blocking.

Hidden media

Once media is confirmed sensitive, the original stays in place, heavily blurred and darkened, with a “Sensitive media hidden” notice and a “Why hidden?” button.

Shows a public-domain painting over the blur. This only changes how hidden media looks, so it can be switched at any time, even while X protection is locked. With it off, clicking hidden media opens “Why hidden?”.

Applies when a post’s media is confirmed sensitive. The original text comes back if the media is released.

Disables the Like button and the L shortcut on posts whose media is hidden, so you never endorse what you have not seen. Unliking still works.

Temporary reveals

Inside “Why hidden?”, hold the button to show a post briefly. Each post gets a few seconds a day, shared across its images and all tabs. Letting go, switching tab, or leaving the page hides it again. Videos stay paused.

Profile protection

Works from account flags: accounts that X itself marks as sensitive. Profile pictures are not checked by the classifier. A flag lasts only for the current page session and is never saved, so a mistaken flag can’t censor an account for good.

Profile pictures and banners

In timelines, replies, lists, and on profile pages. Your own picture is never blurred.

Flagged accounts only

Blurring images is quiet, so it can apply to strangers broadly. Replacing names and collapsing replies change how threads read, so they only ever apply to flagged accounts.

Replaces the display name (also in mentions, the profile bar, and the tab title), hides the @handle, and hides the bio and website on their profile. Virtue names stay the same for each account, so threads stay readable.

Replies fold into one line. “Show…” opens “Why hidden?” and uses the same hold-to-reveal allowance as media; there is no one-click reveal.

Manual hides

Right-click a post or its media on X, then choose Custos: hide this post’s text or hide this image / video. Choices are saved on this device and still apply when the level is Off.

    About Custos

    Site timers, known adult-site blocking, and sensitive-media protection on X.

    On your device

    Classification and domain matching run locally. Rules, locks, manual hides, and reveal usage stay in this browser profile. Custos does not upload your browsing history or media for analysis.

    Browser access

    Website access lets Custos enforce your rules and protect media on X. Locks protect settings inside Custos; the browser can still disable or remove the extension.
